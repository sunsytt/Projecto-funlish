# Funlish

Funlish es una plataforma web de reforzamiento para la enseñanza de inglés universitario. Centraliza el material de estudio, las actividades interactivas y el seguimiento académico en un solo lugar.

- El **docente** organiza contenidos por unidades, crea actividades mediante plantillas y da seguimiento al rendimiento de sus grupos.
- El **alumno** practica de forma individual, acumula puntos por habilidad (reading, writing, listening, speaking) y compite en un ranking grupal.

Proyecto académico de la Universidad Politécnica de Chiapas.

## Módulos

**Alumno:** Mis Clases, Material, Actividades, Foro y Perfil con ranking del grupo.

**Docente:** Material, Actividades, Foro y Alumnos, organizados por grupo.

## Tecnologías

- Frontend: React + Vite + Tailwind CSS v4 + React Router v6
- Backend: Java + Javalin + Maven
- Base de datos: MySQL / MariaDB
- Despliegue: frontend en Vercel; backend en una instancia EC2 de AWS Academy

## Cómo ejecutarlo

```bash
git clone https://github.com/sunsytt/Projecto-funlish
cd Projecto-funlish
npm install
npm run dev
```
